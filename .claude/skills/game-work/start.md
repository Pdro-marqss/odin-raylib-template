# Iniciar demanda

Coloque uma demanda de `work/` em execução.

## Entrada

`/game-work start <nome>`

## Procedimento

1. Localize a demanda e leia o brief.

2. Confira o status:
   - `rascunho`: siga.
   - `execução`: a demanda já está em execução. Informe e trate como
     `/game-work resume`.
   - `concluída`: não reabra. Informe e sugira criar uma demanda nova que
     referencie esta.

3. Leia apenas os documentos referenciados pelo brief que forem
   necessários para entender o trabalho.

4. Atualize o brief:
   - `Status` para `execução`;
   - `Estado atual`;
   - `Próximo passo`, se ainda estiver vazio.

5. Não crie documentos adicionais sem necessidade.

## Resultado

Informe:

- qual demanda foi iniciada e seu caminho;
- o objetivo registrado no brief;
- o próximo passo definido.

Depois disso, continue o trabalho a partir do próximo passo.
