# Documentação

Conhecimento permanente sobre como o jogo funciona.

`work/` registra como o trabalho foi feito; `docs/` registra o que
continua valendo depois que ele terminou.

A maioria dos documentos nasce do fechamento de uma demanda. A exceção é
`concept.md`: a ideia central do jogo, semeada pela skill `game-init`
antes de qualquer demanda existir, e mantida viva por ela enquanto a
ideia evolui.

| Assunto | Descrição | Documento |
|---|---|---|
| Plataformas | Como o jogo é construído para cada plataforma e o que o alvo web exige do código | [platforms.md](platforms.md) |

Cada documento criado ganha uma linha nesta tabela.

Quando o número de documentos justificar, agrupe a tabela em seções — não
antes.
