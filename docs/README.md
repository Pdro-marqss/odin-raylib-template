Conhecimento permanente sobre como o jogo funciona.

`work/` registra como o trabalho foi feito; `docs/` registra o que
continua valendo depois que ele terminou.

| Assunto | Descrição | Documento |
|---|---|---|

e cada documento criado ganha uma linha nesta tabela.

antes.
